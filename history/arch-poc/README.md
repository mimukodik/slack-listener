# The first phase: making the whole listener testable

From 2026-11-17 to 2026-11-23 we took a working Slack listener and made the whole program run in a simulated world, one small step at a time. Each step was paired with one testing method, a pass bar set in advance and a time limit. The listener stayed in daily use throughout. This page summarises what was done, in order, and what was left open at the pause. The [dated decision log](https://github.com/mimukodik/slack-listener/blob/3a36ac759c5fccb0456b17121b81b6a6716a1aff/DECISIONS.md) has the full detail, with commands and measurements.

**The checkpoint at `3a36ac7`** (the numbers the coordinator recorded; rerun them with the pinned scripts at that commit):

- 2,000 listener seeds of 120 actions, no failures;
- 680,613 exhaustive sequences up to seven actions, no violations;
- 500 hub seeds of 80 calls;
- 1,367 replayed TLA+ model paths.

The simulated world is itself a model, so a mistake shared by the fake and the checker can escape.

## Open at the pause

- **The next method:** [Hegel](https://github.com/hegeldev/hegel), a property-based testing engine built on Hypothesis, as a shrinker that cuts a failing run down to a short, readable case, compared with fast-check's.
- **Remaining hardening:**
  - a ban on type casts;
  - shorter functions;
  - assertion density;
  - the remaining lint rules;
  - a bound on the incoming event queue. The rule text for when it fills is the owner's decision.
- **Faults and time:**
  - fault knobs;
  - clock jumps;
  - deadlines;
  - measuring how long a dead connection takes to notice;
  - rule checks at every crash point;
  - shrinking failures to replayable runs.
- **Two simulator blind spots,** found by the swarm experiment: [two bugs no run reached](swarm/README.md#two-bugs-no-run-reached).
- **The hub:** coordination across two programs (B2), the UI's view state (B3) and Slack delivery (C). Whether the hub belongs beside the agent platform or inside it is an open owner decision.
- **Upstreaming the Effect patch** waits for the owner.

After the pause, the work moved to [the language comparison](../../experiments/listener/README.md).
